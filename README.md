# 残高ダッシュボード

現在の残高から、固定費・クレジットカードの引き落とし予定を差し引いて「着地予想残高」を確認するための家計管理ツールです。

## できること

- 現在の残高を入力
- 固定費・クレカなど「カード」ごとに引き落とし項目(名前・金額・引落日)を管理
- 本日の日付を基準に、まだ来ていない引き落としだけを自動集計
- 残高 − 今後の引き落とし予定 = 着地予想残高 を自動計算
- 追加時にオリコ・楽天・アメックス・ENEOS・三井住友・イオン・JCBなどのカードや家賃（固定費）をプリセットから選択可能(自由入力もOK)

## 技術

- Vanilla JavaScript / HTML / CSS のみ(フレームワーク・ビルド不要)
- ブラウザ内の状態管理のみ(保存機能なし・リロードで初期データに戻ります)
